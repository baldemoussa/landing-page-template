# Landing Page Template

A single page with a navigation bar, a summary, a short feature list, a contact form, and a footer. The page is a fixed width and sits in the center of the window.

## Screenshots

**The page.** Home, About, Services, and Contact stay on this page. The footer links open Facebook, X, Instagram, and LinkedIn in a new tab.

![Landing page with the summary, feature list, contact form, and footer](docs/screenshots/page.png)

**Hover.** The Summary block turns a muted brown. Features and Call to Action do the same. A nav or footer link turns teal and gains an underline.

![The same page with the Summary block in its hover color](docs/screenshots/summary-hover.png)

## On the page

- **Summary** describes setting up the command line, a GitHub account, and a Git repository
- **Features** lists Feature 1, Feature 2, and Feature 3
- **Call to Action** says “Get in touch with us!” and shows a form

The form asks for a name, an email, a password, and a message. Every field is required. After the browser checks an entry, an invalid field gets a red border and a valid field gets a green border.

## Open it

Open `index.html` in a browser.
